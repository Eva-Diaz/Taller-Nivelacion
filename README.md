## 🛠️ Proyectos y Ejercicios Incluidos

A continuación se detallan los programas creados en este repositorio:

### 1. 🔠 Conteo de vocales y consonantes
*   **Ubicación:** `ConteoVocalConsonante/src/ConteovocCons.java`
*   **Descripción:** Programa en Java que cuenta y separa las vocales y consonantes de una palabra o frase.

### 2. 🧮 Calculadora Básica
*   **Ubicación:** `Calculadora Basica/src/CalculadoraBasica.java`
*   **Descripción:**  Una calculadora sencilla para realizar operaciones de suma, resta, multiplicación y división.

### 3. 🔄 Invertir Cadenas
*   **Ubicación:** `InvertirCadenas/src/InversionCadena.java`
*   **Descripción:** Programa que toma un texto ingresado por el usuario y lo invierte de posición.

## 🚀 Cómo Ejecutar los Proyectos

1. Clona este repositorio en tu computadora.
2. Abre la carpeta principal (`Taller-Nivelacion`) en tu IDE favorito (VS Code, IntelliJ IDEA o NetBeans).
3. Navega hasta el archivo `.java` que deseas probar dentro de la carpeta `src` correspondiente y ejecútalo.
